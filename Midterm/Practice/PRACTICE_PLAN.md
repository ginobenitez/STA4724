## 🎯 **PRACTICE STRATEGIES THAT WORK**

### **1. Active Recall**
- Try to solve problems WITHOUT looking at solutions first
- Write code from memory, then check
- Explain concepts out loud to yourself

### **2. Spaced Repetition**
- Review the same concepts multiple days
- Each time, try to recall from memory first
- Focus extra time on concepts you forget

### **3. Interleaving**
- Mix different types of problems in one session
- Don't just do all regression, then all classification
- This builds better pattern recognition

### **4. Error Analysis**
- When you get something wrong, understand WHY
- Keep a list of common mistakes you make
- Review this list before the exam

### **5. Teaching Method**
- Explain concepts to an imaginary student
- If you can't explain it simply, you don't understand it
- Use analogies and examples
